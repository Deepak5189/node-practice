# Node.JS Project Info (mini project 01)

This subfolder (nodejs-project-info) contains the solution of the first exercise from roadmap.sh for nodejs parctice. The link to the problem statement acan be found here:
-   https://roadmap.sh/projects/nodejs-folder-info

## Output format

This is the output format:

    FolderName: <target-folder-name>,
    Path: <absolute/path/to/the/target/folder>,
    Files: <Number of files inside the target folder>,
    Folders: <Number of subfolder inside the target folder>

## Instructions to run the script:

- The only script required here is folder-info.js along with `node runtime`

## Steps to run

-   Open the terminal where you can access node: Check using `node --version`
-   To run the script: Type `node </to/folder-info.js> </path/to/target/folder.js>`
-   You will get the output as descripbed in the `Output Format`

## Exception

-   In case you provided non-existing target folder, you will get:

    error: could not read folder: `<target-folder-name>`
